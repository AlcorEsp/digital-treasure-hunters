# Digital Treasure Hunters

![Digital Treasure Hunters Logo](images/icon128.png)

Una extensión de navegador cooperativa que transforma la navegación web en una experiencia de búsqueda del tesoro interactiva. Los usuarios adoptan diferentes roles y trabajan en equipo para descubrir pistas ocultas por toda la web.

## 🎮 Concepto

**Digital Treasure Hunters** convierte la navegación web cotidiana en una experiencia gamificada:

- Cada usuario selecciona un rol especializado con habilidades únicas
- Mientras navegas por Internet, la extensión detecta "pistas" ocultas basadas en tu rol
- Forma equipo con amigos que tienen diferentes roles para resolver desafíos más complejos
- Completa misiones y descubre tesoros digitales a través de la colaboración

## ✨ Características

- **Sistema de roles únicos**: Elige entre Decodificador, Traductor, Analista Visual, Historiador o Navegador
- **Detección contextual**: Cada rol puede encontrar diferentes tipos de pistas en las páginas web
- **Colaboración en equipo**: Une fuerzas con otros jugadores para resolver misiones más complejas
- **Sistema de misiones**: Progresa a través de desafíos con dificultad incremental
- **Integración perfecta**: Se superpone a tu navegación normal sin interrumpir tu experiencia

## 🚀 Instalación

### Requisitos
- Google Chrome, Microsoft Edge o cualquier navegador basado en Chromium
- Modo desarrollador habilitado en la página de extensiones

### Pasos
1. Clona este repositorio o descarga el código fuente
```bash
git clone https://github.com/tu-usuario/digital-treasure-hunters.git
```

2. Abre la página de extensiones en tu navegador
- Chrome: `chrome://extensions/`
- Edge: `edge://extensions/`

3. Activa el "Modo desarrollador" (interruptor en la esquina superior derecha)

4. Haz clic en "Cargar descomprimida" y selecciona la carpeta del proyecto

5. ¡La extensión está instalada! Haz clic en el ícono de la extensión para comenzar tu aventura

## 📱 Uso

1. **Selecciona tu rol**: Al iniciar por primera vez, elige el rol que mejor se adapte a tu estilo:
   - **Decodificador**: Especialista en descifrar códigos y mensajes ocultos
   - **Traductor**: Experto en idiomas y símbolos extraños
   - **Analista Visual**: Detecta patrones y detalles ocultos en imágenes
   - **Historiador**: Conoce la historia de sitios web y referencias culturales
   - **Navegador**: Detecta patrones de navegación y ubica sitios de interés

2. **Navega normalmente**: Explora la web como lo harías habitualmente. La extensión analizará las páginas en busca de pistas.

3. **Descubre pistas**: Cuando encuentres una pista, la extensión te notificará. Cada tipo de rol puede detectar diferentes tipos de pistas.

4. **Completa misiones**: Acepta desafíos que te guiarán en tu búsqueda.

5. **Forma un equipo**: Invita a amigos a unirse a tu equipo para colaborar en misiones más difíciles.

## 🔍 Roles y sus habilidades

| Rol | Descripción | Tipos de pistas |
|-----|-------------|-----------------|
| **Decodificador** | Especialista en patrones de texto | Códigos ocultos, mensajes cifrados, comentarios en código fuente |
| **Traductor** | Experto en idiomas y símbolos | Textos en idiomas extranjeros, caracteres inusuales, patrones lingüísticos |
| **Analista Visual** | Maestro de los detalles visuales | Imágenes con mensajes ocultos, patrones de color, elementos visuales sutiles |
| **Historiador** | Conocedor de referencias culturales | Alusiones históricas, referencias a eventos pasados, contenido antiguo |
| **Navegador** | Experto en patrones de navegación | URLs inusuales, estructuras de navegación complejas, enlaces ocultos |
