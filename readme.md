# Digital Treasure Hunters

Una extensión de navegador cooperativa que convierte la navegación web en una emocionante aventura de búsqueda del tesoro. Los usuarios asumen diferentes roles y trabajan en equipo para descubrir pistas ocultas por toda la web.

![Digital Treasure Hunters](images/icon128.png)

## Descripción

**Digital Treasure Hunters** transforma tu experiencia de navegación diaria en un juego colaborativo. Cada usuario elige un rol especializado (Decodificador, Traductor, Analista Visual, Historiador o Navegador) y utiliza sus habilidades únicas para detectar diferentes tipos de pistas ocultas en las páginas web que visita.

El objetivo es formar equipos con jugadores de diferentes roles para resolver misiones y descubrir tesoros digitales ocultos. A diferencia de otros juegos, este se integra perfectamente con tu navegación normal, añadiendo una capa de diversión y misterio a tu actividad en línea habitual.

## Características principales

- **Roles especializados**: Cada jugador elige un rol con habilidades únicas para detectar diferentes tipos de pistas.
- **Misiones cooperativas**: Las misiones requieren colaboración entre diferentes roles para ser completadas.
- **Integración con la navegación**: El juego se superpone a tu navegación normal, sin interrumpir tu experiencia web.
- **Pistas dinámicas**: Las pistas varían según el rol del jugador y el contenido de la página.
- **Progresión del juego**: Desbloquea nuevas misiones y desafíos a medida que avanzas.

## Instalación

### Método 1: Desde el navegador (Desarrollo)

1. Descarga o clona este repositorio en tu computadora
2. Abre tu navegador Chrome/Edge/Brave y ve a la página de extensiones:
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`
   - Brave: `brave://extensions/`
3. Activa el "Modo desarrollador" en la esquina superior derecha
4. Haz clic en "Cargar descomprimida" y selecciona la carpeta del proyecto
5. ¡Listo! La extensión estará instalada y lista para usar

## Cómo empezar

1. **Selecciona tu rol**: Al iniciar por primera vez, se te pedirá que elijas un rol especializado
2. **Completa la misión introductoria**: Navega por la web para encontrar tu primera pista
3. **Únete a un equipo**: Conecta con otros jugadores para formar un equipo completo
4. **Desbloquea nuevas misiones**: A medida que progreses, se desbloquearán nuevos desafíos

## Los roles y sus habilidades

### Decodificador
- Especialista en descifrar códigos y mensajes ocultos
- Puede detectar texto codificado en las páginas web
- Recibe herramientas especiales para resolver acertijos basados en texto

### Traductor
- Experto en idiomas y símbolos extraños
- Detecta textos en idiomas poco comunes que podrían contener pistas
- Descifra símbolos y caracteres especiales que otros roles no pueden entender

### Analista Visual
- Detecta patrones y detalles ocultos en imágenes
- Encuentra pistas escondidas en elementos visuales de la página
- Identifica cambios sutiles en colores y formas que podrían ser mensajes codificados

### Historiador
- Conoce la historia de sitios web y referencias culturales
- Descubre conexiones entre diferentes páginas web basadas en su historia
- Identifica referencias históricas o culturales que contienen pistas

### Navegador
- Detecta patrones de navegación y ubica sitios de interés
- Encuentra rutas ocultas entre páginas web
- Descubre enlaces escondidos y patrones de URL que conducen a nuevas pistas
